This project is a Java-based energy bill calculator built to practice Object-Oriented Programming (OOP) concepts. It calculates the final bill for multiple consumers by applying specific tariff flags and low-income discounts based on their kWh usage, and concludes by generating a summary report with the total revenue, average consumption, and highest bill recorded.

How to Run

1- Open your terminal in the project folder.

2- Compile the files using: javac *.java

3- Run the application using: java Main
